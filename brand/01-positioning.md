```
Для [домашних энтузиастов, офисов с подпиской, кафе/HoReCa],
которым нужен [вкусный спешелти без лишней сложности],

которая [подчёркивает терруар и даёт чистый, яркий профиль — от everyday до funky].
В отличие от [масс-маркета и «модного» кофе ради картинки],
мы [обжариваем с индивидуальным подходом к каждому зерну и честно показываем, что в чашке].
```

## УТП (уникальное торговое предложение)

1. **Терруар в приоритете** — обжарка раскрывает происхождение, а не маскирует его.
2. **Личный QC** — проверка качества проходит через основателя/обжарщика.
3. **Индивидуальный профиль** — подход к каждому зерну, не «один профиль на всё».
4. **Гибкий ассортимент** — интересный лот → малые партии → пока есть в наличии.
5. **Помол под метод** — зерно + помол под V60, AeroPress, эспрессо и т.д.
6. **B2B под заказ** — кофейни, офисы (уточнить условия в 09-open-questions).

## Ценности бренда

| Ценность | Как проявляется |
|----------|-----------------|
| Прозрачность | Понятные описания вкуса, происхождение, дата обжарки |
| Ремесло | Малые партии, ручной контроль |
| Честность | Не обещаем «лучший кофе в мире» — показываем чашку |
| Любопытство | Funky-лоты, смена ассортимента |
| Доступность по смыслу | Спешелти без лишней сложности в коммуникации |

## Архетип

**Craftsman + Curator** — мастер обжарки + отборщик интересных лотов.

## Мы / Не мы

| Мы | Не мы |
|----|-------|
| Спешелти с читаемым терруаром | Масс-маркет, «просто крепкий» |
| Чистый, яркий профиль | Хипстерский кофе «для картинки» |
| Everyday + espresso + funky | Фиксированная бесконечная линейка SKU |
| Рыночные цены, честная ценность | Демпинг и «скидки каждый день» |
| Micro-batch, пока есть | Склад на год вперёд без смены лотов |
