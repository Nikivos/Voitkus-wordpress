## Персона 1: «Домашний энтузиаст»

| | |
|---|---|
| **Имя (рабочее)** | Аня / Марк |
| **Возраст** | 28–45 |
| **Где** | Варшава + Польша (доставка — уточнить) |
| **Оборудование** | V60, AeroPress, иногда эспрессо дома |
| **Мотивация** | Вкуснее, чем супермаркет; интерес к происхождению без «курса Q-grader» |
| **Боли** | Непонятные карточки; старый кофе; не знает, какой помол |
| **Что ищет** | Чистый, яркий кофе; подсказку по завариванию; свежая обжарка |
| **Триггер покупки** | Рекомендация, Instagram, поиск «specialty coffee Warsaw» |
| **Средний чек** | 250 г, иногда 2 пачки или подписка |
| **Сообщение бренда** | «Терруар, который слышно. Помол под ваш метод.» |

**Jobs to be done:**
- Купить кофе, который стабильно радует утром (everyday).
- Попробовать что-то интереснее на выходных (funky).
- Понять, как заварить без ошибки.

## Персона 2: «Офис / подписка»

| | |
|---|---|
| **Имя (рабочее)** | Офис-менеджер / владелец малого бизнеса |
| **Мотивация** | Хороший кофе для команды без возни |
| **Боли** | Заканчивается неожиданно; некачественный «офисный» кофе |
| **Что ищет** | Регулярная поставка, 1 кг, один понятный профиль или ротация |
| **Средний чек** | 1 кг × N, подписка |
| **Сообщение бренда** | «Свежая обжарка в офис по расписанию.» |

**Jobs to be done:**
- Настроить подписку и забыть.
- Иметь один контакт (B2B).

---

## Персона 3: «Кафе / HoReCa»

| | |
|---|---|
| **Имя (рабочее)** | Владелец кофейни / head barista |
| **Мотивация** | Уникальный вкус в чашке; партнёр по обжарке |
| **Боли** | Нестабильная обжарка; нет гибкости под меню |
| **Что ищет** | Обжарка под эспрессо/фильтр, объёмы, сроки |
| **Сообщение бренда** | «Обжарка под вашу чашку — обсудим профиль.» |

**Jobs to be done:**
- Запросить дегустацию / образцы.
- Согласовать профиль под эспрессо-машину.
