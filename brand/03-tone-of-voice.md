# 03. Tone of Voice (голос бренда)

## Суть голоса

**Спокойный эксперт-ремесленник:** знаем про кофе много, говорим просто, уважаем вкус клиента.

## Принципы

| Делаем | Не делаем |
|--------|-----------|
| Короткие, ясные фразы | Маркетинговый пафос («революция», «лучший в мире») |
| Конкретика: вкус, метод, обжарка | Пустые прилагательные («премиальный», «уникальный» без факта) |
| «Вы» / «мы» — на равных | Поучения и снисходительный тон |
| Показываем вкус словами, которые понятны | Жаргон ради жаргона (если термин — поясняем) |
| Честно про ограниченность лота | Искусственный дефицит и FOMO |

> **Запрещённые формулировки в бренде:** слово «снобизм» и производные; «для избранных»; «настоящие ценители только».

## Шкала тона

```
Формальный ████░░░░░░ Разговорный
Серьёзный   ██████░░░░ Лёгкий
Экспертный  ███████░░░ Простой
Сдержанный  ████████░░ Эмоциональный
```

Целевая точка: **разговорный + экспертный + сдержанный**.

## Словарь бренда

### Используем

- терруар, происхождение, лот, партия
- чистый, яркий, сбалансированный
- обжарка, дата обжарки, профиль
- everyday, эспрессо, funky *(как внутренние теги — на сайте можно RU: на каждый день / эспрессо / эксперимент)*
- помол под метод, V60, AeroPress

### Избегаем

- «хипстерский», «трендовый», «инстаграмный»
- «масс-маркет» в агрессивном сравнении с конкурентами по имени
- «сноб», «гурман высшего сорта»

## Примеры: до / после

| ❌ Плохо | ✅ Хорошо |
|----------|-----------|
| Элитный кофе для истинных ценителей | Спешелти с акцентом на терруар — от утренней чашки до ярких лотов |
| Уникальный премиальный продукт №1 | Лот из Эфиопии: цитрус, цветы, лёгкое тело. Обжарка 12.05. |
| Вы завариваете неправильно | Подскажем помол и рецепт под ваш V60 |
| Снэбовский спешелти | Кофе для тех, кто хочет вкус глубже «просто чёрного» |

## Микрокопи (UI магазина)

| Место | Текст |
|-------|-------|
| CTA главная | Смотреть кофе / В каталог |
| Корзина | Оформить заказ |
| Помол | Выберите помол или «целые зёрна» |
| Нет в наличии | Лот закончился — следите за новинками |
| Подписка | Кофе по расписанию — без лишних заказов |
| B2B | Обжарка для кафе и офисов |
