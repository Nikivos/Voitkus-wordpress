# 04. Продуктовая архитектура

## Обзор ассортимента (MVP)

| Параметр | Значение |
|----------|----------|
| SKU на старт | 4–5 |
| Формат | Зерно (+ помол под метод) |
| Фасовки | 250 г, 1000 г |
| Ценообразование | Рыночные цены *(конкретные PLN — TBD)* |
| Линейка | Не фиксированная — ротация по лотам |

## Три «корзины» вкуса (теги / категории)

Используются для навигации, фильтров и коммуникации — **не обязательно постоянные SKU с одним именем**.

| Тег | Для кого | Профиль | Пример заваривания |
|-----|----------|---------|-------------------|
| **Everyday** | Каждый день, офис | Сбалансированный, чистый, понятный | Фильтр, French press |
| **Espresso** | Эспрессо дома и в кафе | Сладость, тело, стабильность в корзине | Эспрессо-машина, молоко |
| **Funky** | Ищущие интересный вкус | Яркий, экспериментальный терруар | V60, AeroPress |

## Карточка товара (обязательные поля)

### Коммерция
- [ ] Название лота (рабочее + происхождение)
- [ ] Цена 250 г / 1000 г
- [ ] Наличие / «малый остаток»
- [ ] Вариант помола (список методов)

### Происхождение
- [ ] Страна, регион
- [ ] Ферма / кооператив *(если есть)*
- [ ] Сорт (арабика, сортовой состав)
- [ ] Высота, обработка (washed, natural, …)

### Обжарка
- [ ] Дата обжарки
- [ ] Профиль (filter / espresso / omni)
- [ ] Рекомендация: через N дней лучше всего *(опционально)*

### Вкус
- [ ] Ноты (3–5 дескрипторов)
- [ ] Кислотность / тело / сладость *(простая шкала или слова)*
- [ ] Brew guide (кратко + ссылка на рецепт)

### Брендинг лота (упаковка)
- [ ] **Цвет этикетки** — по **профилю/ощущению** (everyday / espresso / funky); несколько SKU могут делить цвет → [10-packaging-system.md](./10-packaging-system.md)
- [ ] HEX для сайта / WooCommerce `accent_color`

### Медиа
- [ ] Фото упаковки (цвет читается) / зерна
- [ ] *(опционально)* фото чашки / SCA-style

## Помол — варианты для WooCommerce

| Значение атрибута | Подпись для клиента |
|-------------------|---------------------|
| `whole` | Целые зёрна |
| `espresso` | Под эспрессо |
| `v60` | Под V60 / pour-over |
| `aeropress` | Под AeroPress |
| `french_press` | Под French press |
| `moka` | Под моку |
| `custom` | Другой метод — укажите в комментарии |

## Жизненный цикл лота

```
Закупка зерна → Профилирование обжарки → QC (основатель)
    → Публикация на сайте → Продажа до исчерпания
    → Снятие с витрины / архив → Новый лот
```

## Naming convention (рекомендация)

`[Страна] [Регион/ферма] · [Обработка] · [Тег: Everyday|Espresso|Funky]`

Пример: `Ethiopia Guji · Natural · Funky`
