## Конструкция пакета

| Элемент | Спецификация |
|---------|----------------|
| Формат | Stand-up pouch (doypack), matte black |
| Этикетка | Горизонтальная полоса по центру (~40% высоты), **цвет = ID лота** |
| Типографика на этикетке | Sans-serif, жирный; контраст: тёмный текст на светлых полосах / светлый на тёмных (orange) |
| Клапан | Degassing valve, верх справа |
| Вес на пакете | 250 g *(1 kg — отдельный макет, тот же цвет)* |

## Иерархия на этикетке (фиксированная сетка)

```
┌─────────────────────────────────────────────┐
│ roasted in Poland          ETHIOPIA         │
│ for curious people         Sidama           │
│                                             │
│ VOITKUS              NUTKI:                 │
│ coffee roastery      Herbata / Cytrusy / …  │
│    ──○──○──○──○──  (профиль обжарки, знак)   │
│ OBRÓBKA │ SELEKCJA │ ROAST │ WYSOKOŚĆ      │
│ Naturalna│ 74158   │Filter │ 2050 m n.p.m. │
└─────────────────────────────────────────────┘
```

### Блоки (не менять позиции между лотами)

| Зона | Содержание | Язык |
|------|------------|------|
| Верх слева | `roasted in Poland for curious people` | EN |
| Верх справа | Страна (CAPS) + регион | EN |
| Центр слева | `VOITKUS` + `coffee roastery` | EN |
| Центр | **Профиль обжарки** — та же кривая + 4 точки, что в [логотипе](./11-logo.md) | — |
| Центр справа | `NUTKI:` + 3 дескриптора | PL |
| Низ | 4 колонки: обработка, селекция, roast, высота | PL + EN (roast) |

### Обязательные поля на каждом лоте

- [ ] Страна + регион  
- [ ] NUTKI (3 ноты через `/`)  
- [ ] OBRÓBKA (обработка)  
- [ ] SELEKCJA (сорт / код, напр. 74158)  
- [ ] ROAST (Filter / Espresso / Omni)  
- [ ] WYSOKOŚĆ (м n.p.m.)  
- [ ] Дата обжарки *(на задней стороне или нижний край — уточнить при печати)*  
- [ ] Вес, EAN *(если нужен для retail)*

## Цветовая система лотов

### Как делают в индустрии

| Модель | Суть | Когда ок |
|--------|------|----------|
| **1 цвет = 1 SKU** | Каждый лот уникальный цвет | Мало SKU, стабильная линейка годами |
| **1 цвет = профиль/настроение** | Цвет = everyday / funky / espresso или «ощущение» вкуса | **Ротация лотов**, micro-roastery ✅ |
| **1 цвет = происхождение** | Ethiopia всегда тёплый, Colombia холодный | Много лотов одной страны |

Для Voitkus (4–5 SKU, смена лотов, 3 профиля) — **модель 2** логичнее, чем «цвет навсегда за одним названием».

### Правило Voitkus (v2) ✅

1. **Цвет привязан к профилю вкуса / тегу**, а не к уникальному SKU.  
2. **Два и более лота могут делить один цвет**, если совпадают дескрипторы и «ощущение» (например, два funky).  
3. **Различие на полке:** крупно **СТРАНА + РЕГИОН** на этикетке (у тебя уже так) — цвет не единственный ID.  
4. Если в одном теге **два лота одновременно** и путаница на полке — второй оттенок **внутри семьи** (напр. Orange и Magenta оба = funky) или тонкая полоска/номер партии.  
5. **Lime** — limited / эксперимент / новинка.

> Старое правило «1 цвет = 1 активный SKU» — **отменено**.

### Палитра → профиль (не → один лот)

| HEX* | Цвет | Профиль / ощущение | Примеры лотов (может быть несколько) |
|------|------|--------------------|--------------------------------------|
| `#FFE600` | Yellow | **everyday** — na co dzień, zbalansowany | Colombia Huila, Guatemala Huehuetenango |
| `#FFCBA8` | Peach | **espresso** — słodycz, karmel, body | Brazil Cerrado |
| `#00E5FF` | Cyan | rezerwa | — |
| `#FF6A00` | Orange | funky — яркий, фруктовый, «солнечный» | Ethiopia Sidama Natural |
| `#FF2D9A` | Magenta | funky — цветочный, сочный, экспрессивный | Rwanda Nyamasheke |
| `#B8F500` | Lime | limited / новый лот / эксперимент | следующий drop |

*\*Снять точные HEX из print PDF / Figma.*

**MVP сейчас:** 2 everyday (Yellow), 1 espresso (Peach `#FFCBA8`), 2 funky (Orange + Magenta) — без конфликта «два лота на один цвет», но **если завтра второй Sidama-профиль** — может сесть на Orange рядом с текущим Sidama, пока старый лот не сошёл.

### Пример эталона (макет на Orange)

| Поле | Значение |
|------|----------|
| Origin | Ethiopia · Sidama |
| NUTKI | Herbata / Cytrusy / Kwiaty |
| OBRÓBKA | Naturalna |
| SELEKCJA | 74158 |
| ROAST | Filter |

## Связь упаковка ↔ сайт ↔ WooCommerce

| Упаковка | Сайт / WooCommerce |
|----------|-------------------|
| Цвет этикетки | `accent_color` = цвет **профиля** лота (может повторяться у разных SKU) |
| ETHIOPIA / Sidama | Название товара + атрибуты |
| NUTKI | Поле «ноты вкуса» |
| 4 колонки низа | ACF: processing, variety, roast_type, altitude |
| ROAST | Фильтр + вариации помола |
| Tagline | Footer / About |

**Карточка в каталоге:** чёрный фон + цветная полоса слева (как на пакете).
